# June 2026 benchmark reference

This directory contains the frozen SQbricks-only benchmark results generated
in June 2026. The original execution date and benchmark family remain visible
in each CSV filename.

These files provide a versioned historical reference for reviewing benchmark
selections and capability changes. They are not used directly by
`regression-light-check` or `regression-large-check`; those commands use the
machine-specific baselines stored in the parent baseline directories.
